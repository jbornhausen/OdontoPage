# OdontoPage 🦷💻
Uma página pessoal feita com **HTML e CSS**, misturando um pouco da minha trajetória na Odontologia com meus estudos atuais em tecnologia.

Como também tenho pós-graduação em **UI/UX**, quis criar uma página com uma proposta mais visual, divertida e diferente — menos “currículo tradicional” e mais “essa sou eu em formato de site”.

## O que tem na página?

- Um pouco sobre mim
- Minhas skills
- Experiências
- Livros que indico
- Formas de contato

## Tecnologias

- HTML
- CSS
- Google Fonts

## Objetivo

Praticar estruturação de páginas, estilização, navegação por seções e construção de uma identidade visual própria usando apenas HTML e CSS.

Feito com carinho, cores e um pouquinho de caos criativo ✨
